# BINV2150A-slides
Slides pour le cours BINV2150A - Javascript avancé

Avant tout, il faut installer les dépendances du projet. Pour cela, vous devez ouvrir le terminal dans le dossier correspondant et entrer la commande :

`npm install`

## Comment afficher une présentation

Pour afficher la présentation, vous devez ouvrir le terminal dans le dossier correspondant et entrer la commande :

`npm run dev`

La présentation est ensuite disponible dans le navigateur à l'adresse http://localhost:3030

## Comment exporter les slides en PDF

Pour exporter les slides en PDF, vous devez ouvrir le terminal dans le dossier correspondant et entrer la commande :

`npm run export`
